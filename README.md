# threads-affi

Threads（Meta）でのアフィリエイト投稿を自動化するためのツールです。

## 概要

Threads API を使って、アフィリエイトリンクを含む投稿の作成・予約・自動投稿を行うことを目指しています。
手作業での投稿の手間を減らし、決まったスケジュールで安定して発信できるようにすることが目的です。

### 主な機能（予定）

- 投稿文とアフィリエイトリンクの管理
- 投稿の予約（日時の指定）
- Threads API による自動投稿
- 投稿結果の記録
